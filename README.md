# Консольный калькулятор

## Назначение проекта
Консольное приложение на Python для выполнения математических операций. Позволяет выполнять несколько вычислений подряд в одном запуске.

## Какие задачи решает программа
- Запрашивает два числа и операцию.
- Поддерживает операции: `+`, `-`, `*`, `/`, `//`, `%`, `^`.
- Позволяет выполнять несколько операций подряд без перезапуска.
- Обрабатывает неизвестную операцию и деление на ноль.
- Проверяет корректность ввода чисел и ответа на продолжение.

## Инструкция по запуску
1. Установите Python 3.
2. Откройте терминал в папке с `main.py`.
3. Выполните:

```bash
python main.py
