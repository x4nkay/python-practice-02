# Консольный калькулятор

## Назначение проекта
Небольшое консольное приложение на Python для выполнения основных математических операций над двумя числами.

## Какие задачи решает программа
- Запрашивает у пользователя два числа и математическую операцию.
- Поддерживает операции:
  - `+` — сложение;
  - `-` — вычитание;
  - `*` — умножение;
  - `/` — деление;
  - `//` — целочисленное деление;
  - `%` — остаток от деления;
  - `^` — возведение в степень (в Python выполняется как `**`).
- Обрабатывает неизвестную операцию.
- Обрабатывает деление на ноль.
- Проверяет корректность ввода чисел (защита от ввода букв).

## Инструкция по запуску
1. Установите Python 3.
2. Сохраните программу в файл `1.py`.
3. Откройте терминал в папке с файлом.
4. Выполните команду:

```bash
python 1.py
